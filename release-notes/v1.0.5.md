Update Nix Mind directly from the app, starting with this release.

- Choose **Nix Mind → Check for Updates…** to find, download, and install future releases. Optional automatic checks run once a day; you choose when to install and relaunch.
- Update metadata and archives are signed with Ed25519 and verified before extraction. Pending topic edits are committed before installation, with the normal document save/quit flow preserved.
- Adding a child or sibling branch now preserves your current zoom and pan, including on large maps. Use **Fit to window (Command-0)** when you want to see the whole map.

**Upgrading from 1.0.4 or earlier:** install 1.0.5 manually once. Save your maps, quit Nix Mind, then replace the app in Applications with this version. Saved `.nixmap` documents remain separate. Future releases can be installed using **Check for Updates…**.

Requires macOS 14 or later. Universal downloads support Apple Silicon and Intel. Ad-hoc signed; not Developer ID signed or notarized. See the README for installation instructions.
