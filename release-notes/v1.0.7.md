Choose where arrows appear on each connection.

- Use **Connection → Line → Arrow position** to select **None**, **Start**, **End**, or **Both ends**.
- Choose **None** to hide both arrows, or move arrows to the parent end, child end, or both ends of the line.
- Arrow position changes preserve the existing arrow shape and other line formatting, and support save/reopen and undo/redo.

**Updating from 1.0.5 or later:** choose **Nix Mind → Check for Updates…** to download and install this release. If you use 1.0.4 or earlier, install this version manually once.

Requires macOS 14 or later. Universal downloads support Apple Silicon and Intel. Ad-hoc signed; not Developer ID signed or notarized. See the README for installation instructions.
