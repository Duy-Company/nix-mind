Nix Mind 1.0 is the first macOS release: a native place to turn ideas into mind maps and structured outlines.

## Included

- A draggable, zoomable canvas with automatic branch arrangement and no six-branch root limit.
- Direct topic editing, notes, branch colors, and native Undo/Redo.
- Fonts, text formatting, alignment, node shapes, fill colors, and border styling.
- Automatic, left-to-right, and right-to-left branch structures.
- Multiple sheet tabs in one workbook.
- Editable Mind map and Outliner views.
- Native `.nixmap` workbooks plus modern Xmind and FreeMind import/export.
- Local MCP with 14 tools for reading and editing topics, styles, and sheets from an AI client.

## Install

Requires **macOS 14 or later**. Both downloads contain the same universal app for **Apple Silicon and Intel**.

- **DMG:** open the disk image and drag Nix Mind into Applications.
- **ZIP:** extract it and move Nix Mind.app into Applications.
- **SHA256SUMS.txt:** checksums for both downloads.

This release is **ad-hoc signed**, not Developer ID signed or notarized. macOS may block the first launch; see the README for Apple's supported Open Anyway flow. No account or AI subscription is required.

## Current limits

FreeMind exports only the active sheet. Advanced Xmind features such as attachments, relationships, summaries, and legacy XML workbooks are not supported. Xmind desktop visual fidelity and every supported macOS version have not been manually verified.
