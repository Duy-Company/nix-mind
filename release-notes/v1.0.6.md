Style connections and turn branches into clearly labeled paths.

- Choose curved, straight, or right-angle connections. Customize line color, thickness, solid/dashed/dotted strokes, and arrows at either end.
- Add any text to a connection and format its font, size, color, emphasis, and alignment. Click the label directly to edit it on the canvas.
- Labels sit transparently in a gap in the line. The selection highlight blends around the text while keeping the selected connection easy to see.
- Resize label containers horizontally, vertically, or diagonally using their edges and corners. Labels start at their natural text size; adjust the width to wrap text as needed.
- Click empty canvas space, use the deselect button, or press Escape outside text editing to clear the current selection. Drag empty space to pan while preserving selection.
- Connection styles, labels, and label sizes support save/reopen and undo/redo.

**Updating from 1.0.5:** choose **Nix Mind → Check for Updates…** to download and install this release. If you use 1.0.4 or earlier, install this version manually once.

Requires macOS 14 or later. Universal downloads support Apple Silicon and Intel. Ad-hoc signed; not Developer ID signed or notarized. See the README for installation instructions.
