Fixes MCP client configuration when connecting Nix Mind to VS Code.

- MCP Settings now offers **VS Code** and **Other clients (mcpServers)** formats, defaulting to VS Code.
- VS Code configuration puts `nix-mind` directly under `servers` and explicitly uses `type: stdio`.
- Added client-specific examples, paste instructions, and troubleshooting for `file:///undefined`.
- Added regression checks for both formats, executable paths with spaces, and transport selection.

If VS Code currently reports `file:///undefined`, replace the malformed `servers.mcpServers` wrapper with the direct `servers.nix-mind` entry shown in MCP.md. This release does not change the mind-map file format or MCP tools.

Requires macOS 14 or later. Universal downloads support Apple Silicon and Intel. The app remains ad-hoc signed, not Developer ID signed or notarized; see the README for first-launch instructions.
