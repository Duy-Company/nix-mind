Find ideas faster with a new translucent Search popup.

- Open Search with **Command-F** or the magnifying-glass button in the toolbar.
- Search topic titles and notes in the current sheet or all sheets in the file.
- Results rank exact titles and word prefixes first, with case- and accent-insensitive matching, any word order, acronyms, and small title typos. Vietnamese searches support unaccented letters, including d for đ.
- Matching text appears in bold with a color highlight. Results include parent context and note snippets centered on the match.
- Use Up/Down to choose a result, Return to jump to it, and Escape to close. Canvas navigation centers the node at a readable zoom; Outliner expands its ancestors and scrolls to it.
- Search runs in the background with cached snapshots and cancellation of superseded queries.
- Prevents the hidden canvas from receiving edit shortcuts while Search or Outliner owns input. Native text input preserves input-method composition.

In-app update infrastructure is prepared but **disabled** while signing setup is pending. This version performs no automatic update checks. Download and install this release manually; regular source pushes now run Debug CI, while release packaging runs only when explicitly requested.

**Updating manually:** save your open maps and quit Nix Mind, then replace the existing app in Applications with this version. Saved `.nixmap` documents remain separate and compatible.

Requires macOS 14 or later. Universal downloads support Apple Silicon and Intel. Ad-hoc signed; not Developer ID signed or notarized. See the README for installation instructions.
