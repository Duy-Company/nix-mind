Improves navigation and editing in large mind maps, with more flexible side panels.

- Faster canvas panning and zooming through cached geometry and text layout, with spatial indexing to draw visible nodes and connections.
- Lighter overview rendering when zoomed out, while preserving saved node styles and readable detail when zooming in.
- Node dragging previews changes smoothly and commits a single undoable edit when released. Concurrent document or MCP edits cancel stale drag previews.
- Resize the topics sidebar and inspector by dragging their dividers.
- Show or hide either side panel from the toolbar to make more room for the canvas.
- Adds canvas, drag, and spatial-index regression checks to CI.

Includes the Nix Mind identity and MCP configuration improvements from previous releases. Existing files remain compatible.

Requires macOS 14 or later. Universal downloads support Apple Silicon and Intel. Ad-hoc signed; not Developer ID signed or notarized. See the README for installation instructions.
